++CONTENUTI DELL'ARCHIVIO++
	--> TheLnife.jar : file jar eseguibile
	--> Original_project_all_folders.rar : progetto originale, contiene le
	    le cartelle con i file sorgenti (.java), i file *.class e il file .pom
	--> cartella javadoc : documentazione javadoc del progetto
	--> Manuale Tecnico.pdf : manuale tecnico
	--> Manuale Utente.pdf : manuale utente

++REQUISITI++
L'applicazione richiede Java JDK 17 e il sistema operativo Windows 10.
NOTA: l'applicazione è stata sviluppata e testata su Windows 10. Alcune librerie per l'interfaccia grafica sono platform-dependent, 
sebbene esse siano incluse nel file jar non è garantito il corretto funzionamento sui sistemi operativi
Linux e Mac. (abbiamo testato l'applicazione su mac con java JDK e ha funzionato)

++AVVIARE L'APPLICAZIONE++
Doppio click sul jar eseguibile o tramite linea di comando digitare:
java -jar TheKnife.jar
